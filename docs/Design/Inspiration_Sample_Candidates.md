# Inspiration Sample Candidates

## Executive Summary

This is a small, reviewable first batch of visual inspiration/sample candidates for Sam to inspect before any assets are used in the app.

- Scope: 12 candidates across living rooms, dining rooms, bedrooms, and home offices.
- Current app living-room samples are included first so Sam can compare them against new options.
- No production assets were replaced.
- No app wiring was changed.
- Candidate images have been downloaded into `docs/Design/inspiration-sample-candidates/` for local review. No app wiring or production asset replacement has been done.
- Downloaded review copies are in `docs/Design/inspiration-sample-candidates/`; approved production assets should still be copied/wired only after Sam shortlists them.
