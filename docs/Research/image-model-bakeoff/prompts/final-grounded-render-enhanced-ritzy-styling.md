# Final Grounded Render Prompt: Enhanced Ritzy Styling

Use the first input image as the original room photo. Use the second input image as the selected concept direction. Use the third input image as a catalog product-reference contact sheet.

Create one photorealistic editorial residential final render for Ritzy Studio. The result should feel like a high-end but livable Dubai villa or large townhouse interior, fully resolved by an interior designer. It should not feel like bare staging, a CGI showroom, generic beige luxury, an IKEA catalog, or a hotel lobby.

Architecture preservation:
- Preserve the source room architecture, camera perspective, windows, doors, ceiling planes, openings, columns, staircase if present, fireplace if present, built-ins, AC vents, sockets, wall boundaries, floor boundary, and fixed joinery.
- Do not invent fantasy architecture or move major openings.
- Use the selected concept's overall design direction, composition, warmth, and lighting intent, but keep the original room constraints credible.

Catalog product grounding:
- Product 1 / anchor sofa: preserve the selected sofa's silhouette, color family, upholstery material, arm shape, back height, proportions, leg/base treatment, and distinctive features where possible.
- Product 2 / accent chair: preserve the selected chair's silhouette, color family, material, profile, arm/back shape, seat proportions, legs/base, and distinctive features where possible.
- Product 3 / table or color-material reference: preserve the color/material family, top/base contrast, finish, and scale if it is used in the composition.
- Do not invent major furniture that conflicts with the selected product list.
- If a role is not represented in the catalog references, style it as a non-commerce interior-design layer rather than pretending it is a catalog item.

Allowed non-commerce styling layers:
- Wall art, mirrors, paneling, shelves, picture lights, lamps, sconces, books, trays, vessels, branches or greenery, cushions, throws, flowers, small decor, curtains, and considered surface styling.
- Add layered lighting where appropriate: floor lamps, table lamps, sconces, picture lights, pendants, ceiling lighting, or cove lighting.
- Add rugs with correct scale and placement. Rugs should anchor the seating group and not float undersized in the room.
- Add side tables and coffee-table styling so the room feels finished and lived in.

Product-role gap note for this prompt:
The catalog references include seating and a table/color-material reference, but do not include lighting, wall art, media unit, curtains, rug, books, vessels, flowers, cushions, or throws. Those layers may be added as non-commerce styling, but do not imply they are selected catalog products.

Output quality:
Make the final image look like real editorial interior photography, not illustration, watercolor, CGI showroom smoothness, sketch, mood board, or collage. Use natural daylight plus warm practical lighting, realistic upholstery grain, wood/stone texture, rug fibers, wall finish, physically plausible shadows, and correct furniture scale.

Avoid: wrong sofa/chair color, conflicting major furniture, fake TV if the room does not call for it, empty unresolved walls, strange paintings, bad scale, overdecorated render fluff, unwanted text, product labels, price tags, retailer logos, watermarks, or shopping-list text.
