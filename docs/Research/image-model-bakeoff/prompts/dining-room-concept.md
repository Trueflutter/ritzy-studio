# Dining Room Concept Generation Prompt

Use the uploaded source room photo as the base image.

Create one photorealistic editorial interior design concept for a Dubai villa or large townhouse dining room. Preserve the source room's camera angle, window/door placement, ceiling line, walls, floor boundary, fixed joinery, sockets, AC vents, and structural architecture.

Design a residential dining room around a properly scaled dining table, realistic chair spacing and pull-out clearance, a sculptural over-table fixture centered on the table, layered warm secondary lighting, and a sideboard or wall focal point where space allows. Use restrained tablescape styling, tactile materials, and residential hosting realism; include a rug only if it can plausibly support pulled-out dining chairs.

Style direction: quiet luxury, warm contemporary, collected-not-matched, high-end UAE residential realism. Use walnut, travertine or limestone, warm ivory upholstery, brushed bronze, matte plaster or paneling, soft perimeter lighting, and believable window light/shadows.

Avoid fantasy architecture, restaurant/banquet scale, showroom matching, generic catalog staging, warped chair legs, impossible reflections, text labels, price tags, watermarks, logos, or any visible retailer claims.
